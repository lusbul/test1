# Енерголабораторія — 10 клас

Статичний інтерактивний урок із комп'ютерного моделювання. Без бібліотек, серверів, облікових записів і зовнішніх ресурсів.

## Публікація на GitHub Pages
1. Створіть публічний репозиторій GitHub.
2. Завантажте в корінь репозиторію `index.html`, `style.css`, `script.js`.
3. Відкрийте Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Після публікації сторінка буде доступна за адресою `https://ВАШ-ЛОГІН.github.io/НАЗВА-РЕПОЗИТОРІЮ/`.

## Функції
- Розгортання/згортання короткої теорії.
- Симулятор із повзунками, перемикачами та живим розрахунком.
- До 6 дослідів, таблиця й стовпчикова діаграма.
- Тест із трьох питань.
- Гіпотеза, висновок, PDF через друк браузера, експорт CSV.
- Адаптація до смартфонів, українська мова, звертання на «Ви».

Модель спрощена: сталий ККД 85%, постійна потужність навантаження. PDF створюється через «Друк → Зберегти як PDF»; автоматичного PDF-файла без діалогу друку немає.
